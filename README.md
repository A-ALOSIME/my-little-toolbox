# My Little Toolbox

A bilingual, static directory of useful software. No build step or server is required; the site is suitable for GitHub Pages.

Open `index.html`, or serve the folder locally with `python -m http.server 8000`. Edit `data.js` to update the directory and `artcraft.js` for the ArtCraft collection. Download links lead to official product or download pages; availability, releases, and platform support can change.

The Arabic font uses a locally installed Thmanyah font when available and falls back to system fonts. Supply a licensed webfont to make it consistent for all visitors.
7-Zip offers a graphical Windows application and official command-line versions for macOS and Linux.
